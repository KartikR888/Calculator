# Calculator 

A clean, responsive single-page Calculator built by **Kartik R** using semantic HTML and modern CSS. This Repository highlights core web development fundamentals, responsive grid design, micro-interactions, and native javascript integration.

---

## 🚀 Features

* **Better UI:** Clean section featuring simple ui ux design system.
* **Quick Response:** Morden javascript makes action and response.
* **Adaptive Layout:** Fully responsive breakpoints that adjust the gallery grid from 3 columns on desktops to 2 columns on tablets, and a single column on mobile devices.
* **Interactive UI Elements:** Styled badges, smooth transitions, and hover animations built with CSS.

## 🖥️ Getting Started

To view and run this project locally:

1. Clone or download the repository to your local machine.
2. Open `FirstWebsite.html` directly in any modern web browser (Google Chrome, Firefox, Safari, Edge).
   ```bash
   # On macOS
   open FirstWebsite.html

   # On Linux
   xdg-open FirstWebsite.html

   # On Windows
   start FirstWebsite.html
   ```
